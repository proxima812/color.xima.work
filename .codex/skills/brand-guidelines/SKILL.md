# color.xima.work Brand Guidelines

Используй этот скилл при изменении UI, лейаутов, визуальных стилей и внешнего вида компонентов.

## 1) Основа продукта

- Продукт: curated gradient gallery для дизайнеров и frontend-разработчиков.
- Главная ценность: быстро найти градиент, оценить его визуально и скопировать CSS.
- Визуальный язык: чистый, быстрый для сканирования, с фокусом на сами градиенты.
- Интерфейс не должен спорить с карточками градиентов: декор вторичен, контент первичен.

## 2) Цвет и поверхности

- Градиенты являются главным цветовым акцентом.
- Интерфейсные поверхности должны оставаться нейтральными и читаемыми в светлой и тёмной темах.
- Не добавляй случайные новые палитры, если задача не просит изменить бренд или визуальный стиль.
- Для UI-состояний используй существующие Tailwind-паттерны и соседние компоненты как источник правды.

## 3) Геометрия и композиция

- Сохраняй компактную структуру галереи, контролов, фильтров и карточек.
- Не превращай рабочую галерею в лендинг без явного запроса.
- Карточки должны оставаться удобными для сравнения градиентов.
- Изменения в сетке должны проверяться на mobile и desktop, чтобы названия, теги и кнопки не ломали раскладку.

## 4) Компоненты

- Основные UI-зоны: `src/components/colors/*`, `Header.astro`, `Footer.astro`, `BaseLayout.astro`.
- Для gradient cards сохраняй читаемые labels, tags, copy action и preview-поверхность.
- Для фильтров и поиска сохраняй быстрый scanning-flow и понятные active/empty states.
- Для header/theme/locale controls сохраняй доступность, keyboard/focus behavior и locale-aware ссылки.

## 5) Анимация

- Предпочитай короткие CSS/Tailwind transitions.
- Не добавляй тяжёлую motion-библиотеку без явной необходимости.
- Соблюдай `prefers-reduced-motion`.
- Анимация не должна мешать просмотру цвета, чтению текста или копированию CSS.

## 6) i18n и текст

- Локали проекта: `en`, `ru`, `es`, `zh`, `tt`, `kk`, `uk`.
- Default locale: `en`, без префикса в URL.
- Новый UI-текст добавляй во все locale-файлы и подключай через существующие i18n helpers.
- Тексты должны быть короткими и практичными; это инструмент, а не маркетинговая страница.

## 7) Быстрый чек перед сдачей

1. Градиенты остаются главным визуальным сигналом.
2. Tailwind v4 используется без лишних CSS/зависимостей.
3. UI корректен в светлой и тёмной темах.
4. Текст не переполняет карточки, кнопки и фильтры.
5. i18n, SEO и copied CSS behavior не сломаны.
