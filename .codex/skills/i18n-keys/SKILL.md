# i18n keys (short)

Используй этот скилл, когда нужно добавить новый язык или новые ключи переводов.

## Новый язык

1. Создай `src/i18n/locales/<lang>.ts` на основе существующей локали.
2. Добавь язык в `locales`, `localeLabels`, `dictionaries` и SEO/OG locale-маппинг в `src/i18n/index.ts`, если такая структура используется.
3. Добавь язык в `astro.config.mjs` i18n locales.
4. Проверь роутинг локали (`/<lang>/...`) и переключатель языка.

## Новый ключ для компонента

1. Добавь одинаковый ключ во все нужные locale-файлы (`src/i18n/locales/*.ts`).
2. В компоненте используй существующий `useTranslations(locale)` / `t("key")` паттерн.
3. Для интерполяции используй существующий формат проекта.
4. Не оставляй хардкод строк, если это пользовательский UI-текст.

## Правила

- Текущие локали: `en`, `ru`, `es`, `zh`, `tt`, `kk`, `uk`.
- Default locale: `en`, без URL-префикса.
- Ключи именуй по зоне: `home.*`, `colors.*`, `filters.*`, `card.*`, `copy.*`, `nav.*`, `footer.*`, `theme.*`.
- Изменения делай точечно, без рефакторинга всей i18n-системы.
